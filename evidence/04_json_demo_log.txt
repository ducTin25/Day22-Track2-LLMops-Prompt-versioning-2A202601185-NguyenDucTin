Demo: JSON Formatting & Repair

[Valid JSON] PASS
Input:  {"name": "Alice", "age": 30}
Output: {"name": "Alice", "age": 30}

[Markdown fences] PASS / FIX
Input:  ```json {"name": "Bob"} ```
Output: {
  "name": "Bob"
}

[Single quotes] PASS / FIX
Input:  {'name': 'Charlie', 'score': 95}
Output: {
  "name": "Charlie",
  "score": 95
}

[Trailing comma] PASS / FIX
Input:  {"key": "value",}
Output: {
  "key": "value"
}

[Truly invalid] PASS / SAFE FALLBACK
Input:  This is not JSON at all: ??? {]
Output: {"error": "Không thể phân tích JSON", "raw": "This is not JSON at all: ??? {]"}
