[Valid JSON] PASS
  Input:  {"name": "Alice", "age": 30}
  Output: {"name": "Alice", "age": 30}

[Markdown fences] FIXED
  Input:  ```json
{"name": "Bob"}
```
  Output: {
  "name": "Bob"
}

[Single quotes] FIXED
  Input:  {'name': 'Charlie', 'score': 95}
  Output: {
  "name": "Charlie",
  "score": 95
}

[Trailing comma] FIXED
  Input:  {"key": "value",}
  Output: {
  "key": "value"
}

[Truly invalid] SAFE FALLBACK
  Input:  This is not JSON at all: ??? {]
